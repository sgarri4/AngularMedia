Sharingan del desenvolupador · DevTools

  1. Obre les eines de desenvolupador (F12) i la pestanya Network.
  2. Recarrega la pàgina i filtra per Img o Media.
  3. Observa el pes de les imatges i com canvien les peticions en fer scroll.
  4. Prova el mode responsive i comprova els subtítols del vídeo.
  5. Canvia temporalment una ruta per provocar un error 404.
